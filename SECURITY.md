# Security and privacy reporting

Do not publish conversations, account identifiers, tokens, backups or raw runtime
logs in an issue. Use the repository's GitHub **Security → Report a vulnerability**
feature for a suspected disclosure, overwrite or unsafe-path problem. Include a
minimal reproduction with synthetic data and the relevant software versions.

If private reporting is unavailable, open a content-free issue asking the
maintainer to enable a private channel. Do not post exploit details or real data
while waiting. There is no promised response-time service level.

This independent project is experimental. Current source is the supported review
target; there is no long-term support or official Anthropic compatibility promise.
See [the safety model](docs/safety.md) before operating on a profile.
